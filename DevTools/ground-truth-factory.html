KeyAble Factory Ground-Truth

Reads all four layers from a freshly factory-reset keyboard and compares every position against the source-derived dataset (the parsed firmware keymap plus the token to keycode table). A clean pass confirms the parser alignment and the keycode numbers are trustworthy for models you do not own.

This tool only reads the keyboard. It never writes to the board. It does not factory-reset for you; do that in the main Access Key app first (see below).
Do this first: in the main KeyAble app, run Reset Keyboard to Default (factory reset), then come back here and run Steps 1 to 3. (No backup needed on a test board.)

Use Chrome, Edge, or Opera opened from a http://localhost address (WebHID needs a secure context; localhost counts). Plug the keyboard in by USB first.

Ready. Start with Step 1.

Step 1. Load the firmware dataset

Default is the V5 Max ISO (PID 0x0951). Change it to test a different model, then reload. The firmware folder is not in the repository: fetch the commits listed in docs/KEYBOARD-DATA.txt and run the parser to create it.

Step 2. Connect the keyboard

Opens the same device chooser KeyAble uses (VIA raw-HID, usage page FF60). Pick your keyboard and activate Connect.

Step 3. Read all layers and compare

Reads every key on all four layers plus the encoder and compares each to the source-derived value. The result summary appears in the report box.
