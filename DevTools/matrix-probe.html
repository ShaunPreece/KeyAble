Switch matrix probe

Read-only diagnostic. Asks a connected keyboard which physical switches are pressed, using VIA's "switch matrix state" value, and never writes to the keyboard. Close KeyAble first, so only this page talks to the keyboard.

After connecting, press keys one at a time. Each switch that goes down or up is spoken by its row and column. Keys do not need to reach this page: the keyboard reports them whichever window has focus.
