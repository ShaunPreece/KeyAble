KeyAble VIA Probe

Checks four things on a real Keychron keyboard, for the design review's recommendations D-1 and D-2 and the layout data check: what happens when two requests overlap, whether each reply repeats its request, whether a whole layer can be read in one go, and whether the app's layout puts each key where the keyboard has it.

This page only reads the keyboard. It can send only the VIA read commands, and refuses anything else before it reaches the keyboard. Nothing on the keyboard changes.

Open this page from the DevTools server (node DevTools/static-server.js, then http://127.0.0.1:8777/DevTools/via-probe.html) in Chrome or Edge, with the keyboard's switch set to cable and KeyAble closed in other tabs.
