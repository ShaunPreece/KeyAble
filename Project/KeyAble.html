Welcome to KeyAble.

KeyAble allows you to customize your Keychron keyboard and is fully accessible for screen reader users with an easy-to-use interface. It supports various Keychron keyboards and has been tested on the Q6 Max, V5 Max, V6 Max, and B6 Pro.

KeyAble is an independent app and is not affiliated with, endorsed by, or supported by Keychron. We have tested it as thoroughly as we can, but we cannot test every model, layout and computer, so please treat it as use-at-your-own-risk software.

The good news is that remapping does no lasting harm: you can reset any key, or the whole keyboard, from within the app. You can also reset the keyboard to its factory settings without the app, using a key combination on the keyboard itself; see Help for more details.

    Method 2. Use Capture Mode To Select Key.

    Capture mode listens for key presses directly on your keyboard. Press the Start Capture Mode button, then press the key you want to select for customisation. Your selection is confirmed automatically and capture mode ends. To cancel without selecting a key, press Escape twice quickly or press the Stop Capture Mode button.

    Screen reader users: Some keys - such as arrow keys, Home, and End - may be intercepted by your screen reader before reaching this page. If a key is not captured, switch your screen reader to Forms or Application mode first, then press the key. In NVDA press NVDA Key + Space; in Narrator press Caps Lock + Space; in JAWS press JAWS Key + Z. Switch back to normal mode when done. If you cannot capture the key using either method, use the list above instead. Note: KeyAble has been tested with NVDA. Behaviour in JAWS, Narrator, and VoiceOver may vary and has not been fully verified.

    Windows key note: Pressing the Windows key during capture will open the Start menu - this is an operating system restriction that cannot be prevented. The key will still be captured. Simply close the Start menu and return to this page to continue.

    If a key is not detected: if pressing a key produces no response at all - no announcement and no error sound - the key may already have a remap on it from a previous session that stops the keyboard from sending its signal. Go back to Step 1 and reset the keyboard, then try capturing the key again.

      Help.

      Welcome to the help section. KeyAble lets you customize your Keychron keyboard: remap any key, build macros, control the backlight, and back up your setup, all using your keyboard and screen reader alone. This guide covers how to get started, which keyboards are supported, what KeyAble cannot do yet, the emergency reset shortcut if anything ever goes wrong, and answers to the questions we are asked most often. In KeyAble, Alt plus a number, 1 through 5, returns you to any step at any time.

      Getting Started in Three Steps.

      Changing a key takes three steps, one for each of the first three sections of KeyAble.

      1. Go to Step 1, Connect, and connect your keyboard with a USB cable. After the first time, a quick reconnect button appears so you do not need the browser dialog again.
      2. Go to Step 2, Choose a Key, and pick the key you want to change, either from the list or by pressing it in Capture Mode.
      3. Go to Step 3, Choose an Action, and pick what that key should do from the tabs: a single key, a keyboard shortcut, a media control, a system key, a macro, or nothing at all. A Ready to Apply dialog then reads back the change; choose Apply Remap to write it to the keyboard, or Change Action or Change Key to go back.

      Your changes are saved straight onto the keyboard, so they stay with it even on another computer.

      What KeyAble Can't Do Yet.

      Keychron's own Launcher app can do a few things that KeyAble cannot do yet:

      • Change keys on layers other than the Mac or Windows layer and its Fn layer, for example the Fn2 layer.
      • Assign keys that switch between layers.
      • Keys that hold several modifiers at once, such as Hyper (Ctrl, Shift, Alt and Windows) and Meh (Ctrl, Shift and Alt). A single key can already send all four modifiers with another key, from Build a Keyboard Shortcut.
      • Mouse keys, which move the pointer or click from the keyboard.
      • Keys that change the backlight when pressed. The backlight itself is fully controllable from the RGB Lighting section.
      • Keychron's Bluetooth, 2.4 GHz and battery check keys.
      • Japanese and Korean input keys, and Japanese (JIS) keyboard layouts.
      • Keyboard-wide settings such as debounce and polling rate.
      • HE (Hall Effect) and Ultra 8K keyboards.

      The audio and music mode keys are left out on purpose: they need a speaker in the keyboard, which Keychron keyboards don't have. Firmware updates are left out too: a failed update can leave a keyboard unusable, so use Keychron's Launcher for these.

      Emergency Reset. No App Required.

      If your keyboard ever gets into an unexpected state, you can restore all keys to their factory defaults directly from the keyboard without needing this app or a computer. Hold Fn + J + Z for 4 seconds. On a keyboard with two Fn keys, if one does not work, try the other.

      The backlight flashes briefly to confirm the reset. To check without seeing it, press a key you had remapped: it does its normal job again. Or, in this app, Review Changes on This Keyboard lists no changed keys.

      Frequently Asked Questions.

      Answers to the questions we are asked most often, from browsers and cables to macros, sounds, and what to do if something goes wrong.

      Which keyboards does KeyAble work with?

      19 Keychron models across the Q, V, K, and B series, in their ANSI and ISO layouts (JIS is not supported yet). Supported Keyboards has the full list. We have fully tested the V5 Max, V6 Max, Q6 Max, and B6 Pro on real hardware; the others are built from Keychron's firmware data and should work.

      Does KeyAble work with HE or Ultra 8K keyboards?

      Not at the moment. HE (Hall Effect) keyboards, such as the Q1 HE or K2 HE, have magnetic switches whose extra features, like the actuation point and rapid trigger, use Keychron's own commands that KeyAble does not support, and we have not been able to test basic remapping on one. The Ultra 8K models, such as the V6 Ultra 8K, run different firmware (ZMK) that does not use the VIA connection KeyAble relies on, so they cannot be used at all; KeyAble recognises them and tells you so. Both are set up with Keychron's own Launcher instead.

      Which web browser do I need?

      Use a Chromium-based browser such as Chrome, Microsoft Edge, or Brave. These browsers can talk to your keyboard directly over USB. Firefox and Safari cannot do this yet, so KeyAble will not be able to connect in them.

      Can I try KeyAble without a keyboard?

      Yes. In Step 1, choose Try KeyAble Without a Keyboard (Demo), then pick any model from the list. You can explore every step with that model's layout. Nothing is written to a keyboard, and macros need a real keyboard connection.

      Do I have to keep the USB cable plugged in?

      Yes, but only while you are making changes. Remapping needs the wired USB connection. Once your changes are saved you can unplug the cable and go back to Bluetooth or wireless. Your changes stay on the keyboard.

      Will my changes still work on another computer?

      Yes. Everything you set up is saved into the keyboard's own memory, not onto this computer. Plug the keyboard into any machine and your keys, macros, and lighting behave the same, as long as the OS slide switch on the back is set to the same side you made the change for. See the next question if you switch between Mac and Windows.

      I use this keyboard on both a Mac and a Windows PC. What should I pick?

      The keyboard stores a separate Mac layout and Windows layout, chosen by the slide switch on the back. Step 3 says which layout your changes go to, and KeyAble picks the one that matches the switch. If it cannot read the switch, it asks you to choose before your first change. To change it, use the "Choose Mac or Windows Layout" button. If you move the one keyboard between a Mac and a Windows computer and want a change on both, make it once for each layout: shortcuts and System Keys use different keys on a Mac and on Windows. If a change seems to disappear, check that the slide switch matches the layout you edited.

      Do I need to install anything? Is it safe?

      No installation and no internet. KeyAble runs entirely in your browser and talks only to the keyboard in front of you. It has no accounts, and collects or sends no data about you, your keyboard, or how you use it.

      It is a single self-contained file with no third-party code fetched from the web. It reaches your keyboard through the browser's WebHID feature, and only after you pick your keyboard from the browser's permission prompt; you can withdraw that permission at any time. Text you type into a macro, and anything your keyboard reports back, is only ever shown as plain text, never run as code, so a faulty keyboard cannot make the app do anything unintended.

      I pressed Connect but my keyboard is not in the list. What now?

      Check two things. One, the cable is a full USB data cable, not a charge-only cable. Two, the switch on the keyboard is set to cable or wired mode, not Bluetooth or 2.4 GHz. Then press Connect again. It can take a moment for the keyboard to appear, so keep checking the Connect button in the browser dialog.

      If the list shows Keychron Link, that is the 2.4 GHz wireless receiver, not your keyboard, and KeyAble cannot use it. Set the switch to cable and choose the keyboard by its own name instead.

      What is VIA, and do I need to turn it on?

      VIA is the system KeyAble uses to read and change your keyboard's keys over USB. Keychron's QMK keyboards have it built in and always on, so there is nothing to turn on. If your keyboard connects but does not respond, check the switch is set to cable. Very old firmware may not include VIA; updating it with Keychron's own Launcher fixes that.

      Can I undo a change?

      Yes, in several ways. In Step 2, Reset This Key To Default Action puts a single key back, including its Fn action. In Step 1, Review Changes on This Keyboard lists every key you have changed on the current layout and lets you reset any of them, and Reset Keyboard to Default Settings resets everything. Before making big changes you can also save your setup to a file from Step 1, then restore it later if you change your mind.

      Does Reset Keyboard to Default Settings delete my macros too?

      Yes. It returns every key on every layer to its factory setting and clears all macro slots. If you want to keep your macros, save your setup to a file first.

      Why was I warned that a key is risky to remap?

      A few keys are important for keeping control of your keyboard and your screen reader, for example Caps Lock or your only Fn key. If you remap one of these you could lose an important shortcut until you reset. The warning just lets you stop and think; you can still continue if you are sure.

      Why does KeyAble not use Caps Lock or Insert for its own shortcuts?

      NVDA, JAWS, and Narrator use Caps Lock or Insert as their own modifier key, so they take the key press before the page sees it and the shortcut would never work. It is the same reason remapping Caps Lock is flagged as risky.

      What does "Use with the Fn key" do?

      In Step 2, once you have selected a key, there is a checkbox called "Use with the Fn key". Leave it unticked and your new action replaces what the key does on its own. Tick it and the action instead happens only when you hold Fn and press that key, for example Fn plus Home. This is handy when you have run out of spare keys: the key keeps its normal job, and the Fn combination gets the extra action. It works with the knob too, so you can set an action for Fn plus turning the knob. The checkbox applies to one change at a time: it starts unticked each time you pick a key, so tick it again whenever you want the next change to land on the Fn layer. To undo an Fn action, select the key in Step 2 and use Reset This Key To Default Action; if both its normal and its Fn action have changed, you are asked which to reset.

      Can I make a key type a word, a phrase, or a sequence?

      Yes. In Step 3 choose the Macro action. A macro can type text, press keys and keyboard shortcuts, use media controls and system actions, and pause between steps, all from a single key.

      My macro types the wrong symbols, like @ or # or the pound sign.

      This happens when the layout setting does not match your computer. In the Macro panel there is a UK or US layout dropdown. Switch it to match your operating system and the symbols will type correctly. It starts on UK for ISO keyboards and US for ANSI ones.

      In Capture Mode my screen reader will not let me select certain keys.

      Capture Mode switches NVDA into focus mode for you, so that key presses reach KeyAble, and back to browse mode when it ends. Some keys, such as the arrows, Home, and End, can still be taken by your screen reader first. If that happens, switch to focus or forms mode yourself and try again: in NVDA press NVDA key plus Space. If a key still will not capture, use the key list instead, which always works.

      How do I turn the backlight off to save battery?

      Go to the RGB Lighting section, Alt plus 4, and use the Turn Backlighting Off button. On wireless keyboards this noticeably extends battery life. The same section also has brightness, colour, and effect controls if you want them.

      Is there a light theme?

      Yes. KeyAble follows your computer's light or dark setting. To choose for yourself, use the Dark mode button next to the KeyAble title at the top of the page; your choice is remembered.

      What do the sounds mean?

      A rising two-note chirp means a change worked, and a falling one means it failed. A short, rough buzz means a key or entry was not accepted, or that something is needed before you can go on, such as choosing a Mac or Windows layout. A single soft, low tone means a dialog has opened. A single higher beep means Capture Mode has started. If the keyboard is unplugged, you hear the falling chirp and KeyAble returns to Step 1.

      Any tips for Narrator users?

      We recommend leaving Narrator's scan mode off (Caps Lock plus Space toggles it). Scan mode takes over the arrow keys, Enter, and first-letter navigation, which can stop the lists responding as expected and can pull focus back to the previous control after a tab or button moves you to a new panel.

      If Narrator reads out font and colour names, its "Hear advanced detail like text and colour formatting" setting is on. Press Caps Lock plus V to cycle verbosity levels, or choose a lower level under Verbosity in Narrator Settings.

      Is this the official Keychron app?

      No. KeyAble is an independent app and is not affiliated with, endorsed by, or supported by Keychron. Keychron's own tool is at launcher.keychron.com, but it is very difficult to use with a screen reader, which is why we built this.

      Will it work with my keyboard? Please read this.

      Almost certainly, but we cannot promise it. KeyAble is a labour of love from Steven and Shaun, two Keychron fans who wanted a keyboard they could actually remap with a screen reader, built with a lot of help from AI coding tools, not a commercial product with a support department behind it. We have tested it as thoroughly as we can and confirmed several boards on real hardware, but we cannot test every model, every layout, and every computer, so please treat it as use-at-your-own-risk software.

      The reassuring part: remapping keys does no lasting harm to your keyboard. If a key behaves unexpectedly, you can reset it, or all your changed keys, back to their factory settings from within the app, and there is nothing here that can physically damage the hardware. If you do run into trouble, we would genuinely like to hear about it so we can put it right.

      How do I report a problem or a keyboard that is not supported?

      If your keyboard connects but is not recognised, Step 1 shows a keyboard ID and a Report This Keyboard ID button. Include that ID in your report along with your keyboard model if you know it.
